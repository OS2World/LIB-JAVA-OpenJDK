Java 17 on ArcaOS through Odin32  (release 17-0-17b10a3)
========================================================
Runs the 32 bit Windows build of OpenJDK with Odin's PE loader.

1. Install Odin 0.9.1a4 or newer: unzip Odin-0.9.1a4.zip into the boot drive root (it contains the new POWRPROF, WINHTTP,
   MSWSOCK DLLs and the kernel32, ws2_32, iphlpapi ... updates).
2. Download Temurin 17 x86-32 Windows: OpenJDK17U-jdk_x86-32_windows_hotspot_17.0.17_10.zip from adoptium.net
   (SHA-256 34ecb7e53b87ecb288be113ad1c76f3e55e7dc2f2b32427605e356feac95cb74) and unzip it, e.g. to C:\Java17.
3. Copy odin.args to <jdk>\conf\ .
4. Put launcher\java.exe, javac.exe, jar.exe, keytool.exe, jshell.exe in a directory in PATH (copy java.exe
   to javadoc.exe, jlink.exe ... for the other JDK tools: the program name selects the tool).
5. SET JAVA17_HOME=C:\Java17\jdk-17.0.17+10
   SET ODIN_DIR=<directory with pec.exe and the Odin DLLs, normally the Odin lib directory>
6. java -version
   demo\run-demo.cmd           (Swing / Java2D showcase)

Fonts: Java needs TrueType fonts in %SystemRoot%\Fonts (SystemRoot is the Odin directory, e.g. C:\ODINRT\Fonts).
Heap: roughly 700 MB maximum with the default VIRTUALADDRESSLIMIT=1536 in CONFIG.SYS.
Details, tested features and limits are in README.md.
